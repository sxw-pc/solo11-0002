# scan-lab 靶场（仅本地测试）

> **警告**：本目录是一个**故意包含漏洞**的 Flask 应用，只能监听本机、
> 用于 scan-lab 扫描器的开发与回归测试。**禁止**将其暴露到公网，
> **禁止**对未授权目标使用其中的思路或代码。默认只允许 `127.0.0.1`。

## 端点

| 方法 | 路径 | 参数 | 行为 |
| --- | --- | --- | --- |
| GET | `/` | 无 | 首页，包含导航链接、搜索表单和登录表单 |
| GET | `/search` | `q` | 按关键字执行一次演示搜索并渲染结果页 |
| GET | `/files` | `path` | 读取 `target/files/` 下的示例文件并展示内容；对参数再做一次 URL 解码（双重解码缺陷） |
| GET | `/profile` | `id` | 按 id 查询并展示用户资料 |
| GET | `/login` | `username`、`password`（POST） | 校验用户名与口令并返回登录结果页 |

## 故意留下的问题类别

- 反射型 XSS
- 路径穿越
- SQL 注入
- 越权访问（IDOR）

本文件只说明问题类别，不提供任何 payload 或利用步骤。扫描器的验证方式见
`docs/项目说明.md` 与 `src/scan_lab/plugins/`。

## 种子数据

- 用户 3 个：`alice`、`bob`、`admin`（口令为演示用明文，不含真实凭据）。
- 帖子 5 篇，分属上述用户。
- 数据库默认生成在 `target/scan_lab.db`，已在 `.gitignore` 中忽略。

## 运行

```bash
scan-lab serve-target --port 5001
# 或从仓库根目录：
python -m target.app
```

首次启动会自动建库并写入种子数据。请只在本地访问
<http://127.0.0.1:5001>。
